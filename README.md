# Еталонний проєкт після ЛР1

Стан еталонного проєкту дисципліни «JavaScript Frameworks» після першої
лабораторної роботи. До шаблону репозиторію додано компонент «Каталог» у
двох реалізаціях за одним контрактом (`react-ts/src/app/Catalog.tsx`,
`svelte-5/src/app/Catalog.svelte`), п'ять випадків контракту
(`contract/cases.ts`) і заповнені документи ЛР1 (`DOMAIN.md`, `CONTRACT.md`,
`JOURNAL.md`, `ADR-001.md`, `ATTRIBUTION.md`).

Еталон доступний для читання весь семестр. Числа з його журналу не
переносяться в журнал студента, бо отримані на іншій машині й на іншій
предметній області.

## Команди

| Команда | Що робить |
|---|---|
| `npm ci` | встановлення залежностей за файлом блокування |
| `npm run check` | середовище, типи, лінтинг, складання, тести |
| `npm run ready -- 1` | повнота документів ЛР1 |
| `npm run size` | обсяг складання обох реалізацій |
| `npm run diff` | перелік файлів двох реалізацій і рядки різниці |

Перелік усіх команд шаблону наведено в README шаблону репозиторію.
