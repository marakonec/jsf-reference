# Еталонний проєкт після ЛР3

Стан еталонного проєкту дисципліни «JavaScript Frameworks» після третьої
лабораторної роботи. Застосунок далі розвивається у варіанті «запит на
сервері» (`variant-server/`). Варіант «запит на клієнті» прибрано з робочих
просторів, його код лишився в стані після ЛР2. Додано тести трьох рівнів (`variant-server/tests/unit`,
`tests/component`, `tests/e2e`), форму створення з шістьма полями і діалогом
підтвердження очищення, чотири навмисні поломки для протоколу (`variant-server/breakage`) і
заповнені документи ЛР3 (`JOURNAL.md`, розділ 3, `ADR-003.md` з розділами
«Бюджет продуктивності», «Протокол поломок», «Дефекти доступності»).

## Команди

| Команда | Що робить |
|---|---|
| `npm ci` | встановлення залежностей за файлом блокування |
| `npx playwright install chromium` | браузер для наскрізних тестів |
| `npm run check` | середовище, типи, лінтинг, складання, модульні, компонентні і наскрізні тести |
| `npm run ready -- 3` | повнота документів ЛР1…ЛР3 |
| `npm run test:e2e` | лише наскрізні тести |

Наскрізні тести запускають зібраний застосунок на порту 3113 із
`SOURCE_DELAY_MS=0`. Змінна `PW_CHANNEL=chrome` запускає їх у встановленому
Google Chrome замість Chromium, завантаженого Playwright.
