# Навмисні поломки

Чотири файли для протоколу поломок ЛР3. Кожен замінює один справний модуль
застосунку. Поломка вноситься окремим комітом у гілці (вміст файлу
копіюється на місце справного модуля), після чого запускається
`npm run check`, і в протокол записується, які рівні тестів впали.

| Файл | Замінює | Що ламає |
|---|---|---|
| `aggregate.logic.ts` | `src/shared/aggregate.ts` | округлення сумарної маси |
| `SummaryStatus.contract.tsx` | `src/ui/SummaryStatus.tsx` | роль і доступне ім'я підсумку |
| `record-href.scenario.ts` | `src/ui/record-href.ts` | адресу картки запису |
| `catalog-rows.silent.ts` | `src/server/catalog-rows.ts` | позначку в рядках каталогу |

Файли не входять у перевірку типів і складання, бо їхні імпорти записано
відносно місця модуля, який вони замінюють.
